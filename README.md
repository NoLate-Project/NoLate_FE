# NoLate FE

## 네이버 로그인 사전 검수 캡처 가이드

### 검수 전 확인

- Naver Developers의 사용 API에서 `네이버 로그인`을 선택합니다.
- 제공 정보는 `회원이름(필수)`, `이메일 주소(추가)`로 설정합니다.
- 네이버 개발자 콘솔에 모바일 웹 로그인 콜백 `https://nolate.jinuk.dev/api/member/auth/naver/callback`을 등록하고 OIDC `openid` 사용을 허용합니다.
- 앱에는 공개 Client ID인 `EXPO_PUBLIC_NAVER_CONSUMER_KEY`만 둡니다. `EXPO_PUBLIC_NAVER_CONSUMER_SECRET`은 앱 빌드 환경에서 제거합니다.
- BE 배포 환경에 `SNS_NAVER_CLIENT_ID`, `SNS_NAVER_CLIENT_SECRET`을 설정합니다. 서버가 PKCE 인가 코드를 교환하고, 앱의 `nolate://auth/naver` 복귀 URL을 사용합니다.
- 기존에 앱 빌드에 포함된 Client Secret은 네이버 콘솔에서 교체한 뒤 새 값을 서버에만 배포합니다.
- 출시 전 실제 네이버 테스트 계정으로 로그인·신규가입·로그아웃·연결해제까지 TestFlight에서 확인합니다.
- 검수 계정은 Naver Developers의 `테스터 ID`에 등록하고, 이메일 제공에도 동의합니다.

### 캡처 순서

캡처에는 기기 전체 화면과 앱 이름이 식별되도록 포함합니다.

1. **앱 실행**: NoLate 앱 아이콘 또는 앱 시작 화면을 캡처합니다.
2. **로그인 화면**: NoLate 로고, 개인정보처리방침 동의 영역, 네이버 간편 로그인 버튼이 함께 보이게 캡처합니다.
3. **네이버 로그인 클릭**: 개인정보처리방침에 동의한 뒤 `네이버 로그인` 버튼을 누르는 장면을 캡처합니다.
4. **네이버 동의 화면**: 앱 이름 `NoLate`와 제공 항목 `회원이름`, `이메일 주소`가 보이게 캡처합니다.
5. **로그인 완료**: 네이버 인증 완료 후 NoLate 화면으로 돌아오는 장면을 캡처합니다.
6. **홈 화면**: 최초 회원은 캘린더 연결 안내를 마친 뒤 NoLate 일정 홈 화면을 캡처합니다.
7. **프로필 화면**: 홈의 프로필 버튼을 누르고 다음 내용이 한 화면에 보이게 캡처합니다.
   - 계정 정보의 이름, 이메일, 로그인 방식(네이버)
   - `네이버 제공정보 활용`의 실제 사용 목적

### 구현 동작

- 최초 네이버 로그인 시 별도 비밀번호 없이 네이버 식별자, 회원이름, 이메일로 NoLate 회원이 자동 생성됩니다.
- 재로그인 시 같은 네이버 식별자의 기존 회원으로 로그인합니다.
- 이메일 제공에 동의하지 않은 경우 프로필에 미제공 상태가 명시됩니다.
- 로그아웃은 NoLate 로그인 세션과 네이버 SDK 세션을 정리합니다.
- 회원탈퇴는 NoLate 회원 데이터를 삭제한 뒤 네이버 접근 토큰 연결을 해제합니다.

> 실제 사전 검수 제출 전에는 신규 검수 계정으로 1회 전체 흐름을 실행해 자동 회원가입 화면과 제공 정보 노출 여부를 확인하세요.
