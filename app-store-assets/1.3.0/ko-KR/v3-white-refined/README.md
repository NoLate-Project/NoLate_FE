## Rebuild

Run `build.py` with Python/fontTools, then `render.cjs` with Node/Sharp. Font files
and their OFL license are bundled in `fonts/`. No system font installation required.
Python dependencies are listed in `requirements.txt`; the render script also
requires the `sharp` Node module to be installed/resolvable in the build environment.

Cleanup validation (2026-11-03): all nine SVG compositions, including the Figma
board, regenerated byte-for-byte from the bundled sources with fontTools 4.60.1.
