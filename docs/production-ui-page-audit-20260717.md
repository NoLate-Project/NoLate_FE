# NoLate 운영 UI 전수 점검표

점검일: 2026-07-17
범위: 앱 라우트, 주요 모달, 공유 확장, iOS/Android 차이, 운영 오류·빈 상태·접근성
원칙: 비밀키 교체와 배포는 이번 범위에서 제외하고, 화면·동작·안전한 실패 처리만 수정한다.

상태 표기:

- `수정 완료`: 코드와 담당 테스트까지 반영됨
- `검증 완료`: 전체 빌드·회귀 테스트와 가능한 Release 실행 확인까지 통과함
- `실기기 확인`: 카메라·마이크·푸시·외부 OAuth처럼 시뮬레이터만으로 끝낼 수 없는 항목

- 경로 선택 세션은 현재 한 번의 화면 왕복을 위한 인메모리 브리지다. 앱 콜드 스타트는 원래 폼·네비게이션 `sessionId`도 복구하지 않으므로 payload만 AsyncStorage에 남기면 소비 화면 없는 고아 데이터가 된다. 재시작 복구를 추가할 때는 전체 일정 폼 초안과 네비게이션 복원을 하나의 기능으로 설계한다.

- 최종 병합한 Release에서는 로그인, 이용약관, 회원가입 화면을 다시 실행하고 화면 전환·뒤로가기와 배경 접근성 격리를 확인했다.
- 이번 2차 수정본은 현재 시뮬레이터에 NoLate 설치 대상이 나타나지 않아 최신 빌드의 전체 보호 화면을 다시 순회하지 못했다. 로그인 후 서버 연동 화면도 운영 계정 자격정보 없이 재진입하지 않았다. 2차 변경은 라우트·상태 전이 정적 점검, 접근성 단위 테스트, 전체 회귀 테스트, Android 테스트와 iOS Release 빌드로 검증했으며 실제 운영 계정·실기기 스모크 테스트는 아래 출시 전 확인 범위에 포함한다.

판정: 저장소 안에서 완료 가능한 코드·자동 회귀·시뮬레이터 Release 게이트는 통과했다. 다만 HTTPS Universal/App Link는 운영 도메인 배포 파일, Play App Signing SHA-256, 실제 스토어 URL이 없어 출시 전 외부 차단 항목으로 남는다. 스토어 제출 전에는 운영 서명 실기기에서 소셜 로그인, APNs, 캘린더 권한, 카메라·마이크, 실제 지도/대중교통 API, 두 계정 공유 흐름도 마지막으로 확인한다.
