# 설정을 펼치지 않은 재진입·자동 도착 — 2026-11-19

진행 중인 길안내를 캘린더에서 다시 열면 시트는 접힌 상태로 시작한다. 기존 코드에서는 종료 결과를 화면에 반영하는 처리가 `SavedJourneyTrialControls` 안에 있어, 그 설정 영역을 다시 열지 않으면 현재 상세 화면의 자동 도착 처리가 빠질 수 있었다.

종료 관찰을 항상 마운트되는 상세 컨트롤러의 읽기 전용 `useSavedJourneyNavigationLifecycle`로 옮겼다. 현재 계정·일정·저장 경로의 바인딩을 관찰한 뒤, 같은 세션·세대·revision·digest의 native 종료만 반영한다. 조정자가 바인딩을 먼저 정리해도 이 화면이 관찰한 소유권으로 마지막 종료를 대조한다. 초기 조회보다 새 이벤트가 먼저 오면 오래된 조회는 무시하며, 후속 정리 STOPPED가 최초 `DESTINATION_ARRIVED`를 덮지 않는다. 경로·계정·새 세션으로 이 상태를 넘기지 않는다.

종료 스냅샷을 기다리는 짧은 구간에도 지도 길안내 문맥을 유지하고 `상태 확인 중`을 표시한다. 그 사이 새 위치 안내 준비를 제안하지 않는다. 화면을 닫는 것은 추적 시작·복원·종료 명령을 만들지 않는다. 이 변경은 원격 END 전송 경로를 새로 구현한 것이 아니다.
