# 지하철 역 사이의 지도·경로 바·잠금 화면 검증

2026년 11월 20일 iOS 27.0 독립 iPhone 17 Pro 시뮬레이터에서 NoLate 1.3.0 (58) 서명 Release로 확인했다. 자차 시험과 같은 앱 바이너리로 저장된 서울역 → 충무로 환승 → 경복궁 일정을 열었다. XCUITest 한 건이 1,038.846초 만에 통과했다. 실패와 건너뛴 검사는 각각 0건이다.

| 구간 | 화면과 판정 |
| --- | --- |
| 회현 → 명동 | [첫 위치](01-hoehyeon-myeongdong-first-fix.png)와 [다음 위치](02-hoehyeon-myeongdong-later-fix.png)에서 역간 제목이 유지됐다. 4.04초 동안 접힌 경로 바 마커의 가로 중심이 126.78pt에서 129.27pt로 이동했다. |
| 명동 → 충무로 | 열차 관측은 계속 보내면서 승객 위치 입력만 18.6초간 중단했다. [마지막 확인 · 명동](03-myeongdong-history-after-location-loss.png)이 나타났고 현재 위치 마커는 사라졌다. 위치 재개 후 충무로 정차와 [3호선 환승 도보](04-chungmuro-transfer-walk.png)로 이어졌다. |
| 을지로3가 → 종로3가 | 독립 창을 잠근 뒤 [역 사이 이동](05-euljiro-jongno-lock-segment.png)과 [종로3가 정차](06-jongno-lock-confirmed-station.png)를 SpringBoard에서 차례로 검증했다. |
| 경복궁 → 목적지 | 경복궁 하차와 최종 도보를 거쳐 [자동 도착 및 안내 종료](07-automatic-arrival.png)를 확인했다. |

서로 다른 시험 열차가 4호선 4개, 3호선 5개의 모든 정차 위치를 순서대로 보고했다. 각 노선의 최초 승차 확인 후 측정할 수 있는 5개 구간(회현–명동, 명동–충무로, 을지로3가–종로3가, 종로3가–안국, 안국–경복궁)에서 네이티브가 실제로 입력된 위치 표본에 따라 역 사이 이동을 표시했다. 확인된 역 이력과 인접 구간 측정값은 별도로 유지했다. 이전 [정차역 단위 시험 결과](../journey-subway-transfer-20261120/README.md)도 보존했다.

첫 보행 도중 격리 H2의 시험 회원 행을 한 번 잠갔다. 설치된 앱의 자동 세션 재검증이 HTTP 503과 `JOURNEY_STORAGE_BUSY`를 받은 뒤, 잠금 해제 후 같은 세션으로 HTTP 200과 `ACTIVE`를 받았다. 이전 실행에서 동일 종류의 행 잠금이 안내를 중단시켰다. 서버 HTTP 회귀 검사에서 수정 전 409/`C003`과 수정 후 503→200을 재현했고, 저장 행의 버전 충돌은 계속 409로 응답함을 확인했다. 관련 서버 테스트 44건이 통과했다.

최초 완주 빌드의 [충무로 환승 화면](04-chungmuro-transfer-walk.png)에는 연결 복구 후에도 보조 문구에 `AUTOMATIC_SERVER_UNAVAILABLE`이 노출됐다. 아래 최종 빌드에서 같은 조건을 재현해 수정 결과를 확인했다.

ODsay에서 받은 경로·선로와 서울 공식 정차 순서를 사용했다. 위치는 시뮬레이터에 주입했고 열차는 별도의 두 시험 시계로 움직였다. 잠금 화면은 로컬 ActivityKit 갱신으로 확인했다. 실제 APNs의 원격 전달, 지하 실기기 수신 상태, 실운행 열차 식별은 이 실행에서 측정하지 않았다.

완료 후 시뮬레이터의 위치 주입을 해제하고 두 열차 시계를 제거했다. 이 시험의 로컬 서버와 로그 수집기도 종료했다.

## 최종 빌드의 충무로 환승 안내

같은 독립 시뮬레이터에 1.3.0 (58) 서명 Release를 새로 설치했다. 새 시험 계정의 동일 경로에서 H2 행 잠금에 따른 503과 같은 세션의 200 복구를 확인했다. 명동 이후에는 승객 위치 입력만 18.6초간 중단했다. 환승 안내까지의 XCUITest 한 건은 507.944초에 통과했고 실패·건너뜀은 0건이었다. 이 빌드의 Hermes 번들 SHA-256은 `f008f74420a1f0bc05f2df2c87394b104b8044f874de9f35981a9d2e7c11f4a0`이다.

- [복구 후 충무로 안내](08-recovered-transfer-copy.png)에서 “충무로 환승”과 “수도권 3호선 승차 · 환승 도보 약 50m”를 확인했다. 이전 경고 요소가 사라졌으며 앱 접근성 트리의 레이블·값·제목·입력 안내에 기술 코드가 노출된 사례는 0건이었다.
- 3호선 탑승 전에 화면의 종료 버튼을 눌렀다. [종료 화면](09-manual-end-after-transfer.png)에 “위치 안내가 끝났어요”가 표시됐고 저장 경로를 계속 볼 수 있었다. 시험 종료 후 위치 주입, 격리 서버와 로그 수집기를 종료했다.
