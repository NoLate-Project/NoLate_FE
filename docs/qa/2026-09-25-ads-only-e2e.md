# 광고 전용 구독 정책 E2E — 2026-09-25

후속 수정: [Xcode 27 호환 검증](2026-09-25-xcode27-compatibility.md)에서 iOS 27 시작 실패를 해결했다. 아래 내용은 수정 전 최초 실행 결과이며, Device Hub 화면 조작 E2E는 여전히 미완료다.

최종 판정: **API E2E PASS / iOS 26.5 시작 smoke PASS / iOS 27 시작 FAIL / 화면 조작 E2E BLOCKED**.
전체 E2E 통과로 간주하지 않는다. 이번 실행에서는 제품 소스를 수정하지 않았다.

## 환경

- 최신 로컬 작업 트리로 Xcode 27 Release 시뮬레이터 빌드 성공. 앱 버전 1.3.0 (54), SDK iphonesimulator27.0.
- 빌드의 `EXPO_PUBLIC_LOCAL_API_BASE_URL=http://127.0.0.1:5522` 적용. 결과물 `main.jsbundle`에 해당 주소 포함 확인.
- 로컬 API: 127.0.0.1:5522(광고 OFF), 5523(광고 ON 판정 비교).
- 실제 Spring Boot HTTP 서버 + 테스트 프로필 H2 DB + Redis 별도 DB 14/13. JWT 인증, 서비스, JPA 저장 경로를 실행했다. 컨트롤러·서비스를 모킹하지 않았다.
- 스케줄러·Firebase·외부 ETA 공급자는 테스트 프로필에서 비활성화했다. 운영 DB/회원은 사용하지 않았다.
- 각 서버에 합성 FREE/PREMIUM 계정을 seed했다. UI 가입·동의 과정을 검증한 것은 아니다.
- iOS 27 기기: iPhone 18 Pro, `4730DCDB-DA3F-47D1-A820-EE3B612D97F8`.
- iOS 26.5 기기: 새로 만든 NoLate Ads E2E 20260925, `C440407A-D5BA-4D4C-B5C1-D05D2C30351C`.

## 네이티브 실행 결과

### iOS 26.5: 시작 smoke PASS

동일 빌드를 설치·실행해 로그인 화면이 유지되는 것을 screenshot으로 확인했다. 새 설치의 비인증 시작 화면에서 ATT 팝업이 나타나지 않았다.
로그인 이후 FREE/PREMIUM 화면, 알림 권한 프롬프트, 일정 생성·수정 UI는 미검증이다.

[로그인 화면 증거](2026-09-25-ads-only-e2e/ios26-login.png)

### iOS 27: 시작 FAIL

`simctl launch`는 PID를 반환하지만 직후 앱이 SIGTRAP / EXC_BREAKPOINT로 종료됐다. 반복 실행에서도 같은 종료를 관찰했다.
트리거된 첫 프레임은 `___UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption_block_invoke`이다.
현재 AppDelegate는 didFinishLaunching에서 UIWindow를 생성하고, 앱 Info.plist에는 UIApplicationSceneManifest가 없다.
이 증거는 Scene lifecycle 미채택 경로의 시작 실패를 가리킨다. 수정 및 재검증은 수행하지 않았다.

[크래시 요약](2026-09-25-ads-only-e2e/ios27-launch-crash.json)

### Device Hub: UI E2E BLOCKED

현재 Xcode 설치에는 기존 Simulator.app이 없고 Xcode 메뉴에 Device Hub가 제공된다.
Device Hub를 열면 UI 조회가 시간 초과되며 별도 크래시 로그에서 SIGABRT / EXC_CRASH를 확인했다.
`NSWindow(NSDisplayCycle) _postWindowNeedsUpdateConstraints`를 포함한 예외 스택이 관찰됐다.
iOS 26.5 기기 부팅 이후에도 화면 제어가 복구되지 않았다.

[Device Hub 크래시 요약](2026-09-25-ads-only-e2e/device-hub-crash.json)

## 검증 범위와 다음 순서

1. Device Hub 정상 실행을 복구한 뒤 iOS 26.5에서 로그인 → 103번째 알림 일정 확인 → 수정 → 재실행 흐름을 UI로 검증한다.
2. iOS 27 Scene lifecycle 시작 실패를 수정하고 동일 빌드 조건으로 다시 테스트한다.
3. 광고 실제 노출·UMP/ATT 동의 흐름 및 실제 APNs·백그라운드 알람은 이번 결과에 포함하지 않는다.
4. ETA 공급자 정확도·실제 10분 worker 실행·기존 DB 작업 전환은 이번 HTTP 실행에서 검증하지 않았다. 앞선 단위·H2 통합 테스트 결과와 구분한다.

## 재현 자료와 실행 상태

- 앱: `/private/tmp/nolate-xcode27-build54/Build/Products/Release-iphonesimulator/NoLateFE.app`
- 빌드 로그: `/private/tmp/nolate-ads-e2e-build.log`
- 로컬 서버 harness: `/private/tmp/nolate-ads-e2e/AdsE2eServer.java`
- API 시나리오: `/private/tmp/nolate-ads-e2e/scenarios.py`
- 로컬 서버 로그: `/private/tmp/nolate-ads-e2e/server.log`, `server-ads-on.log`
- 테스트 프로필이므로 서버 종료 시 H2 데이터는 소멸한다. 앱의 로컬 테스트 서버 주소를 운영 빌드에 사용하면 안 된다.
- 후속 로그인 조사에서 임시 서버 5522/5523을 종료했다. 당시 사용자의 개발 서버도 5522에 실행 중이었고, 임시 서버가 127.0.0.1 요청을 받아 기존 계정 로그인을 방해했다. 종료 후 localhost와 127.0.0.1 모두 사용자의 개발 서버로 연결되는 것을 확인했다. 임시 H2 테스트 데이터는 서버 종료로 소멸했다.
